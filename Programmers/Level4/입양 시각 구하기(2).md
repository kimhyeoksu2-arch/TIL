## RECURSIVE

WITH RECURSIVE TIME_LIST AS (
    SELECT 0 AS HOUR
    UNION ALL
    SELECT HOUR + 1 FROM TIME_LIST WHERE HOUR < 23
)

재귀 CTE는 크게 세 부분으로 구성됩니다.
Anchor (시작점): 가장 처음 시작할 값을 정합니다. (SELECT 0 AS HOUR)
Recursive (반복부): 이전 결과에 무엇을 더할지 정의합니다. (SELECT HOUR + 1 FROM TIME_LIST)
Termination (정지 조건): 언제 멈출지 정합니다. (WHERE HOUR < 23)
